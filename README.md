# جرّاح PDF

تطبيق أندرويد (Kotlin + Jetpack Compose) لتعديل ملفات PDF: دمج، تنظيم صفحات، وكشف الأعمدة وتبديلها وإخفائها.
البناء يتم بالكامل على GitHub Actions، فلا تحتاج Android Studio.

## الرفع والبناء
1. أنشئ مستودعاً جديداً على GitHub، ثم ارفع محتويات هذا المجلد (يجب أن يظهر مجلد `.github` في جذر المستودع).
2. من تبويب Actions شغّل Build Jarrah PDF (أو ادفع إلى فرع `main`).
3. بعد اكتمال البناء، حمّل `jarrah-pdf-debug` من قسم Artifacts. بداخله ملف APK قابل للتثبيت.

من Termux:
```
git init && git add . && git commit -m "init"
git branch -M main
git remote add origin https://github.com/USER/jarrah-pdf.git
git push -u origin main
```

## إصدار موقّع (اختياري)
أضف Secrets: `KEYSTORE_BASE64` و`KEYSTORE_PASSWORD` و`KEY_ALIAS` و`KEY_PASSWORD`، ثم ادفع وسماً مثل `v0.1.0`.
بدون Secrets يُوقَّع الإصدار بمفتاح debug ويبقى قابلاً للتثبيت.

## البنية
- `core/PdfEngine`: دمج، إعادة بناء الصفحات (ترتيب/حذف/تدوير/استخراج) عبر PdfBox-Android.
- `core/PdfPageRenderer`: عرض الصفحات عبر PdfRenderer.
- `core/TextExtractor` و`ColumnDetector`: استخراج الكلمات بإحداثياتها وكشف الأعمدة من فراغاتها.
- `core/RegionEditor`: تبديل الأعمدة (قص صورة كل عمود وإعادة رسمه) وإخفاؤها.
- `ui/`: الشاشات (الرئيسية، العارض، التنظيم، الدمج، الأعمدة) والثيم العربي RTL.

## حدود معروفة
- PDF لا يحتوي جداول حقيقية، لذلك كشف الأعمدة تقديري ويعمل أفضل على الصفحات التي أغلبها جدول.
- المنطقة التي يُبدَّل فيها عمود تتحول إلى صورة (النص فيها غير قابل للتحديد).
- إخفاء العمود يغطيه ببياض ولا يحذف نصه من الملف.
- الملفات المحمية بكلمة مرور غير مدعومة بعد.

## خطة المراحل
1. (هذه النسخة) العارض + تنظيم الصفحات + الدمج + أول محرر أعمدة.
2. تحرير النصوص والصور، التوقيع، التعليقات والتظليل.
3. محرر جداول متقدم: قص عمود كملف مستقل، دمج أعمدة، إدراج عمود، تحديد الصفوف.
4. كلمة المرور، ضغط الملف، OCR للملفات الممسوحة.
